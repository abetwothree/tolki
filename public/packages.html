List of Packages ​

One of the problems with existing utility libraries is that they only implement a subset of the functionality that Laravel provides. Tolki JS Utilities aims to provide a more complete set of utilities that allow for a more cohesive set of packages that can be used together.

Tolki JS is split into these packages, and you install only the ones you need: @tolki/ts, @tolki/num, @tolki/str, @tolki/types, @tolki/arr, @tolki/obj, @tolki/data and @tolki/collection.

PackageDescription
@tolki/tsUtilities for working with TypeScript like you might in Laravel or PHP.
@tolki/numUtilities for working with numbers like Laravel's Num class.
@tolki/strUtilities for working with strings like Laravel's Str class.
@tolki/typesTypeScript Utilities for Laravel HTTP responses like pagination & models.
@tolki/arrUtilities for working with arrays like Laravel's Arr class.
@tolki/collectionA Collection class similar to Laravel's Collection class.
@tolki/dataUtilities for working with JavaScript objects and arrays in one package.
@tolki/objUtilities for working with JavaScript objects.
